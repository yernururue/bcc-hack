**Итог отчёта:** разработку начинать нельзя — 3 блокирующих дефекта (два противоречия и одна неполнота); тест-дизайн начинать можно. 46 требований (6 составных пунктов разделены), 9 нарушений (blocker 3, major 6), 6 «неясно», 10 вопросов автору с вариантами ответа.

Главное, что нашёл агент: **F-014, противоречие** — после смены порога Ф-4 требует новый push, а Ф-3 разрешает только один push в месяц.

## Независимая проверка

Три ревьюера (Claude Opus 5.5) проверили отчёт: все цитаты настоящие, счётчики сходятся. Ошибки отчёта:
- **F-011 (blocker) ложная:** границы порога есть в Ф-1 и в таблице `amount`. Допущение к вопросу 1 («максимум 10 000 000») противоречит документу.
- **F-015 (blocker) завышена:** 404 для чужой карты в тексте есть, дефект — нет 404 в списке статусов; F-013 повторяет ту же проблему.
- **F-008, F-009 ложные:** коды 401 и 404 описаны. F-007, F-010, F-012 скорее minor, чем major.
- **Пропущено:** критерий приёмки «покупка 31 января → февральский счётчик» противоречит Ф-2 (месяц по дате совершения); ответ 200 с `ERROR` против 400; «чтение порога» без метода чтения; тиыны и тенге; пустой раздел тестирования.
- **Тест-дизайн «можно» спорно:** F-014 мешает написать тест. Правило ужесточено ([ADR-015](../08-decisions.md)), в этом отчёте оно ещё старое.

По разметке `eval/labels/organizers.yaml` (не проверена владельцем) найдено 6 дефектов из 19.

## Как получен

Модель `anthropic/claude-sonnet-5.5` через OpenRouter, версия агента `0b0b506` (указана в паспорте, раздел 1). Команды:

```bash
uv run python main.py docs/before/requirements.md docs/after/requirements-review.md --model anthropic/claude-sonnet-5.5 --max-cost 0.60
uv run python main.py docs/before/requirements.md docs/after/requirements-review.pdf --model anthropic/claude-sonnet-5.5 --max-cost 0.60
```

Оба файла собраны из кэша ответов модели, записанного при реальных прогонах на этом документе, поэтому в паспорте «0 вызовов (+8 из кэша), $0». Реально на эти прогоны потрачено ≈ $0,35.

Отчёт написан агентом, вручную не правился. 2026-11-27 `.md` и `.pdf` перерисованы из этих же JSON текущим рендером без вызовов модели: в PDF исправлен текстовый слой («Ă» вместо «A»), в Markdown вердикт поднят наверх и добавлена легенда «неясно». Содержание находок и вердикт не менялись. Два JSON отличаются только временем запуска и служебными полями: отчёт собирался двумя командами. С тех пор агент дорабатывался (промпт `check_set` v3, повтор пустого ответа модели — [ADR-012](../08-decisions.md)), поэтому повторный прогон текущей версией сделает новые вызовы модели (оценка агента ≈ $0,44 на Sonnet) и может дать немного другие формулировки. Дешёвый прогон для проверки: `--model openai/gpt-6-luna` (центы).
